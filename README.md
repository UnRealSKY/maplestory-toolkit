# 天天的楓之谷工具箱

打王用的計時與提醒。反盾王的階段倒數與魔消時機、女皇五個機制的循環與「一波」判斷、
阿卡伊農的血量門檻——全部能直接讀螢幕上的王血量與遊戲計時、開成浮在遊戲上面的抬頭顯示，
還能裝個小擴充套件用全域快捷鍵在遊戲裡直接按。

**網址：<https://unrealsky.github.io/maplestory-toolkit/>**

> 所有設定與紀錄都存在「你這台電腦的這個瀏覽器」裡，不會上傳到任何伺服器。

## 選王

上方一排是王，選哪隻就換成那隻王的面板。選好的王寫在網址裡——
`https://unrealsky.github.io/maplestory-toolkit/#/boss-toolkit/cygnus` 這種連結可以直接貼給隊友或加書籤。
計時中換不了王，先按「重置」。

## 皮卡啾／粉豆、杜納斯（反盾）

![反盾面板](docs/screenshots/10-pink-bean.png)

面板用整塊顏色說現在是哪一段：**紅＝反盾中、綠＝可輸出**。
主字是「**可輸出到**」幾點幾分（對齊遊戲計時後），本段剩幾秒退成小字，`−1s`／`＋1s` 微調本段。
倒數到 0 會自動推進下一段，看到遊戲實況再按按鈕校正就好。

五顆按鈕：

- **反盾開始**：開戰看到反盾出現時按，開始倒數反盾持續。
- **反盾結束**：進入間隔。
- **反盾阻止成功**：隨時可按，直接進入「反盾被阻止」的可輸出期。
- **魔消成功**：只在間隔可按。**可以魔消的時候這顆按鈕會一直脈動、面板內框跟著呼吸**，按下去或階段換了就停。
  太早放會閃黃三下——反盾重施前就失效了，擋不到。王有 80 秒耐性、技能本身 60 秒冷卻，面板會提醒。
- **重置**。

**接下來**：列出往後幾輪的反盾期間、反盾結束、該用魔消的時刻，紅綠分明。

**參數**：每隻王的反盾持續、間隔、浮動都能改，改回預設會自動移除覆寫；魔消持續是你的技能，換王不變。

## 女皇（循環）

![女皇面板](docs/screenshots/11-cygnus.png)

五個機制各自固定間隔：**反盾 80、變豬 60、小黑屋 90、鎖潛能 90、活屍 60**（秒）。
看到機制出現就按那張卡的「**觸發**」，之後每隔那麼久自動接下一輪，剩 5 秒內轉紅。
「下次」顯示幾點幾分觸發，`−1s`／`＋1s` 只微調那一個機制。「接下來」把五個機制混在一起依時間排。

### 一波

女皇血量低於 11% 會回血到 50%，隊伍靠魔消 20 秒擋住回血、全力打完。
魔消期間變豬、小黑屋、鎖潛能照樣會斷輸出（反盾放了無效、活屍不影響輸出），所以面板最上面那一條看的就是這三個時鐘：

- 綠底「**可以一波（N 秒）**」：N 是還有多少時間可以開始，最後 25 秒（魔消 20 ＋ 喊、反應、施放的 5 秒）是魔消要用的，掉到 0 就翻黃。
- 黃底「**等 N 秒後可以一波**」，第二行列出在等哪幾個機制觸發。
- 「**等待 變豬、小黑屋 觸發**」：那幾個時鐘還沒按過，沒依據不亂說可以。

## 阿卡伊農（血量門檻）與效率推估

阿卡伊農的關鍵不是時間而是血量：**80／60／40／20%** 各出一次招，20% 以下改成每 70 秒一輪。
要開下面的「王血量」擷取才讀得到血量，快到門檻先提醒、跨過去再確認一次。
效率推估沒有機制要算，只有血條與 DPS，拿來看輸出。

## 王血量

按「**擷取畫面**」選遊戲視窗，工具自動找血條、讀百分比；找不到就「**框選血條**」直接指定範圍。
血條旁放王的頭像（從畫面裁下來的），換王或換階段時上一條會凍住放在上面留 10 秒對照。
右邊有 **60 秒最高**與**整場最高**的每秒傷害。

## 遊戲計時

「接下來」右側輸入遊戲剩餘時間按「**對齊**」，之後所有時刻都用遊戲時間顯示；有開擷取畫面的話可以「**從畫面同步**」直接讀。

## 抬頭顯示（子母畫面）

按一下，面板另開一個永遠置頂的小視窗浮在遊戲上面，主視窗那份照樣留著，兩邊看的是同一份狀態。
每個模板一組尺寸，換王跟著調。只有 Chromium 系列（Chrome、Edge）支援。

## 聲音提醒

右上角勾選。階段轉換、機制觸發、該放魔消的時候各響一聲。

## 全域快捷鍵（選用）

打王時遊戲佔滿螢幕，要按面板上的按鈕得先切視窗、點滑鼠、再切回去——那幾秒正是最不能分神的時候。
子母畫面解決了「看得到」，這個解決「按得到」。

網頁只有在自己有焦點時才收得到鍵盤，所以這件事得靠一個小小的 Chrome 擴充套件代收。
**不裝也沒關係，畫面跟以前完全一樣。**

### 六個格子

第 N 格永遠是「**目前這隻王面板上第 N 個動作**」，所以換王不必重綁，鍵位跟畫面由左到右一致：

| 格 | 皮卡啾／粉豆、杜納斯 | 女皇 |
|---|---|---|
| 1 | 反盾開始 | 反盾 |
| 2 | 反盾結束 | 變豬 |
| 3 | 反盾阻止成功 | 小黑屋 |
| 4 | 魔消成功 | 鎖潛能 |
| 5 | （沒有） | 活屍 |
| 6 | （沒有） | （沒有） |

「重置」刻意不給快捷鍵——它會把整場計時清掉，打到一半誤按代價太大，只留給滑鼠。
阿卡伊農與效率推估打王時沒有要按的按鈕，六格都是空的。

### 安裝

1. 下載 [maplestory-toolkit-hotkeys.zip](https://github.com/UnRealSKY/maplestory-toolkit/releases/latest/download/maplestory-toolkit-hotkeys.zip) 並解壓縮（工具箱標題列的「安裝快捷鍵」連的就是這個檔，永遠是最新版）。
2. `chrome://extensions` → 右上角打開**開發人員模式** → **載入未封裝項目** → 選解壓出來的 `maplestory-toolkit-hotkeys` 資料夾。
3. 到 `chrome://extensions/shortcuts`，把「第 1 格」到「第 5 格」各綁一個鍵（第 6 格目前沒有王在用），右邊範圍要選 **全域**（不選全域的話 Chrome 沒焦點時收不到）。
4. 回到工具箱，按鈕角落就會標出各自的鍵。

之後有新版：重新下載、解壓到同一個資料夾覆蓋，再到 `chrome://extensions` 按那張卡的**重新載入**。綁好的鍵不會跑掉。

裝好但還沒綁的格子會顯示 `未綁 3` 這種黃色標記，標題列也會出現「設定快捷鍵」直接帶你去設定頁。

> Chrome 規定快捷鍵**必須含 `Ctrl` 或 `Alt`**（`Shift` 可加可不加），純 F 鍵或單一字母綁不上去。
> 建議避開遊戲自己用的鍵——楓之谷預設 `Ctrl` 是攻擊、`Alt` 是跳躍，綁之前先想一下會不會誤觸。
