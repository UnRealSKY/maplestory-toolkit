# 分寶工具箱

把 Discord 上的分寶紀錄貼進來、用表單快速編輯、自動算好每個人該拿多少錢，
再一鍵複製回 Discord 或直接發佈到論壇頻道。上方導覽切到「分寶工具箱」進入。

> ⚠️ 所有紀錄都存在「你這台電腦的這個瀏覽器」裡（不會上傳到任何伺服器）。
> 換電腦、換瀏覽器或清除瀏覽資料，紀錄就不見了——重要紀錄請先發佈到 DC 留底。

## 分寶紀錄列表

![分寶紀錄列表](screenshots/01-list.png)

開站看到的第一頁，每筆紀錄一張卡片：

- **＋ 新增紀錄**：從空白開始建一筆。
- **貼上 DC 匯入**：把 Discord 上既有的分寶內容整段複製貼上，自動解析成表單。
- 卡片右側狀態徽章：**待售出／✓ 全數賣出**、**未結清／✓ 全部結清**，一眼看出哪團還沒收尾。
- 發佈過 DC 的紀錄另有同步徽章：**✓ DC 已同步**（綠）／**● DC 未同步**（黃，改過內容還沒按同步）。
- **⏸（擱置）**：這團暫時不想列入統計（例如東西還在慢慢賣）就按它，會出現「⏸ 擱置中」黃色徽章；再按一次取消。
- **⧉ 複製**、**🗑 刪除**：複製整筆紀錄／刪除（會先確認）。

## 編輯紀錄

![編輯紀錄](screenshots/02-editor.png)

- **團名**（必填）與**日期**（預設當天）。
- **團員**：輸入 DC 帳號（如 `@awai0774`），有建名冊別名的會自動顯示中文別名徽章。人數不用填，加幾個人就是幾人。
- **交易手續費（%）**：遊戲賣東西時被收走的那筆，新紀錄預設 3%。它跟辛苦費並列，都從團隊總額扣掉再均分。
  沒填的舊紀錄是 0，所以升級不會動到既有金額。
- **團長**：**預設關閉**，要用得先到設定頁把該伺服器的「啟用團長辛苦費」打開（見下方設定）。
  打開後選一位團員當團長並填**辛苦費**，右邊的按鈕切換「**%**（團隊總額的百分比）／**固定**（直接填金額）」。
  辛苦費會先從團隊總額扣掉，剩下的均分給所有人（含團長），團長再額外拿走這筆。
  `人` 留空就是沒有團長，辛苦費欄位不會出現。填超過團隊總額時以總額為上限，不會讓其他人倒貼。
- **總表**：打到的東西一列一項。
  - 最左邊的**狀態**按一下會循環切換：`🛒 待售 → ✓ 售出 → ✖ 不計入`（不計入會自動加上「(價格過低不計入)」註解）。
  - 填**單價、數量**；要消耗剪刀才能交易的東西，再填**剪刀價、剪刀數**（剪刀成本會從該項淨額扣掉）。
  - 品名輸入框會模糊搜尋建議（打「大附」也找得到「大師附加」）；滑鼠停在單價框上會提示歷史成交價。
  - 金額還沒填的項目，輸出時會顯示 `?` 而不是 0。
- **內購區**：團員自己買走的東西，買家只能選團員。每筆可點「模式」切換：
  - **全額**：買家付全額，由其他團員均分（預設）。
  - **均攤**：買家只付原價的 1/人數（例：5 人團買 500 元物品，只付 100，其他 4 人各得 25）。
- **直播檔**：貼直播/剪輯連結。
- **代售**：部分物品交給其他團員賣的情況，填誰代售、賣多少；金額會直接在結算時扣抵，避免金幣轉手被遊戲收兩次手續費。
- **掉落物均分區**：不賣、直接平分給每個人的東西（例如 8 個星星碎片、4 人就一人 2 個），填品名與總數，每人幾個自動算。跟錢無關，不進任何金額。
  總數除不盡人數時會標「⚠ 無法均分 N 人」，而且**不給發佈／同步到 DC**，先在 DC 商量完再改數字。
  主文會多一區「掉落物均分區」列總數，分配名單每個人後面也會接上自己那份（`1000 ｜ 星星碎片x2`）。
  未領總覽每筆的金額行也會接上（`4614 / 3 = 1538 ｜ 星星碎片x2`），最後一行「總計」把跨場次的同名實物相加。
- **三個截圖區**（配合發佈到 DC 使用）：

  ![截圖區](screenshots/07-images.png)

  - **掉落截圖**：發佈時掛在貼文的附件。
  - **領錢截圖**：每張選一位團員，發佈成討論串內的獨立訊息並 tag 對方（「@某人 領錢」）。
  - **外購截圖**：可加註解，發佈成串內訊息（「外購: 註解」）。
  - 加圖三種方式：**選擇圖片**按鈕、把圖**拖拉**進區塊、或按 **Ctrl+V** 貼上——滑鼠停在某區塊上時該區會亮起並顯示「📋 Ctrl+V 貼到這裡」，貼上直接加入；沒停在任何區塊則跳選單問你要放哪一區。
  - 圖片先暫存在瀏覽器，按「發佈／同步至 DC」才上傳；**未上傳**的圖按 ✕ 會先確認（移除即無法復原），**已上傳**的圖按 ✕ 是「待刪除」標記（可反悔），下次同步時才從 DC 移除。

## 分配名單

![分配名單](screenshots/03-distribution.png)

全自動計算，不用按任何按鈕：

```
團隊總額 = 總表淨額 ＋ 代售淨額
每人基本 = (團隊總額 − 交易手續費 − 團長辛苦費) ÷ 人數
個人收入 = 每人基本 ＋ 其他人內購 ÷ (人數−1) − 自己內購 − 自己代售持有額
           團長再額外加上辛苦費
```

金額一律無條件進位。每列右側的**結清**欄有「錢」一顆標籤，有掉落物均分時再多一顆「物」，
點一下就切換已領／未領——在遊戲裡把錢或東西交給誰之後就點誰。主文只看錢那顆。

## 複製回 DC

![複製回 DC](screenshots/04-export.png)

右上角「**複製回 DC**」會產生排好格式的文字，一鍵複製後直接貼回 Discord。
表情符號輸出一律用短碼（`:ok:` 這種寫法），貼到 DC 會自動變成表情。
反過來，DC 上的內容（不管表情是短碼還是圖案）也都能用「貼上 DC 匯入」吃回來。

## 未領總覽

![未領總覽](screenshots/05-pending.png)

上方導覽切到「**未領總覽**」，一頁看完**誰還沒領到什麼錢**：

- 最上方「總共未領未付」是所有人加起來還沒領的錢與實物（同名相加），也就是你還欠大家的。
- 每個還有未結清款項的團員一個區塊：每場一行標題、一行「總額 / 人數 = 每人」（有均分實物就接在後面），有內購、代售或辛苦費時多一行他自己的算式。最後一行「總計」是跨場次的金額加總，實物同名相加。
- 每一行右側都有**複製**按鈕——遊戲內信件不能貼多行，就一行一行複製貼給對方。
- **錢已領／掉落物已領**：在遊戲裡交完錢或東西，直接在這頁點，那一部分立刻從區塊消失，兩個都領完該場才整個消失。錢領了只剩實物時那行就只有實物。
- **開啟 ↗**：另開分頁直達該紀錄的分配名單（兩個分頁的資料會即時互通）。
- 標「**尚有待售**」的場次代表金額可能還會變；被**擱置**的紀錄不會出現在這頁。

## 發佈到 Discord 論壇（Webhook）

不想手動複製貼上的話，可以讓工具直接把紀錄發佈成 DC 論壇貼文，之後內容有更新按一下就同步。

### 第一次設定（只做一次）

1. 在 DC 伺服器建立一個**論壇頻道**（一定要論壇，一般文字頻道做不到）。
2. 若頻道有開「發文必須選擇標籤」，先關掉。
3. 頻道設定 → 整合 → Webhook → 新增 Webhook，複製它的 URL。
4. 回到工具，點右上角 **⚙** 進設定頁 → 選好伺服器 → 在對應的頻道那列貼上 URL 按「驗證」，看到綠色 ✓ 就完成了。

![DC Webhook 設定](screenshots/06-settings.png)

> 🔑 這條 URL 等於發文鑰匙，拿到的人都能用它冒名發訊息——不要貼到公開頻道。
> 共用電腦用完請按「清除」。

### 發佈與同步

- 編輯頁的「**發佈至 DC**」：建立論壇貼文，標題是 `[08-02]混龍第一場` 這種格式。
- 發佈過的紀錄按鈕變成「**同步至 DC**」：內容改了（賣掉東西、有人結清、動過圖片）再按一下，DC 上的貼文就更新。按鈕會顯示轉圈與進度（執行中）、綠色 ✓（成功）、紅色 ✕（失敗，下方會寫原因）。
- 按鈕旁隨時顯示目前狀態：**✓ 與 DC 一致**／**● 與 DC 不同步**／**⚠ 貼文已失效**。
- 貼文內文第一行的標題會帶即時狀態：🛒(2) = 還有 2 項待售、💵(3) = 還有 3 人未領錢、☑️ = 全結案。
- **忘記同步的保險**：有未同步變更時離開編輯頁會先確認；停在編輯頁直接關閉分頁也會跳瀏覽器標準確認。只管**當下這一筆**——刻意留著慢慢賣的場次不會每次都來煩你。資料都存在本機，不會因此遺失。

### 幾個限制（Discord 的規則，不是工具的問題）

- 討論串**標題**建立後就固定了，之後只有內文會更新（你可以在 DC 手動改標題，不影響同步）。
- 內文最多 2000 字元，超過會擋下來提醒你精簡。
- 換電腦或清了瀏覽資料後，用編輯頁的「**綁定貼文**」貼上該貼文的訊息連結（DC 右鍵訊息 → 複製訊息連結），就能把貼文接回來繼續同步。

## 設定（伺服器、頻道與品名清單）

右上角**齒輪 ⚙** 進入。兩層：**伺服器**管名單與辛苦費，底下的**頻道**各有一條 Webhook：

```
伺服器「贖罪券」
  ├─ 名單           ← 別名顯示與真 mention 的來源
  ├─ 啟用團長辛苦費 ← 預設關閉；打開才會出現「團長」卡片、分配才扣辛苦費
  ├─ 頻道 #天團     ← Webhook，發到哪個論壇頻道
  └─ 頻道 #歪團     ← 另一條 Webhook
```

**每筆分寶紀錄選「發到」哪個頻道**（編輯頁「基本資料」的「發到」下拉，伺服器名是組標題、底下列頻道；新紀錄預設帶入設定頁選中的伺服器的第一個頻道）。
發佈、同步走那個頻道的 Webhook；別名顯示、辛苦費跟著那個伺服器走，所以帶不同公會的團不會互相干擾——
同一個人在兩個伺服器有不同暱稱也各顯示各的。

已發佈的紀錄改頻道會先確認，因為貼文綁在原本那個頻道上。

**拖拉**：上排的伺服器 chip 可以拖著換順序；頻道列左邊的 ⠿ 拖到另一列就換順序，拖到上排某個伺服器的 chip 上就整個搬過去——發到那個頻道的紀錄會跟著改用新伺服器的名單與辛苦費設定，搬之前會先確認。每個伺服器至少留一個頻道。

> 改版前「一個群組一條 Webhook」的設定會自動整理：名稱是「伺服器-頻道」的（例如「贖罪券-天團」「贖罪券-歪團」）合併成同一個伺服器、各自變成底下的頻道；沒有「-」的自己一個伺服器，頻道叫「分寶」。既有紀錄照樣找得到原本那條 Webhook，不用重設。

![設定](screenshots/08-lists.png)

### 名單的兩種來源

- **自訂 URL**：把名冊 JSON 放上 GitHub（repo 或 Gist），貼 raw 網址按「抓取並套用」，
  全團共用、改一次大家生效。格式不對會直接提示，不會默默清空。
- **自行輸入**：不靠網路，直接在頁面上編輯表格。編好可按「匯出 JSON」複製內容放上 GitHub。

**品名清單是所有伺服器共用的**（打到的東西不分公會），仍維持預設來源／自訂 URL／自行輸入三種。

名冊每個人有四個欄位：

| 欄位 | 說明 |
|---|---|
| `discordHandle` | `@帳號名`。紀錄裡的團員就是用這個對應 |
| `discordNickName` | Discord 上的顯示名（伺服器暱稱優先）。**同步時會被覆蓋** |
| `alias` | 你自己取的名字。**同步永遠不碰它**，有填就優先顯示 |
| `discordId` | 發佈時把 `@handle` 轉成真 mention 用，沒填的人維持純文字 |

顯示名稱的優先序是 **`alias` → `discordNickName` → `discordHandle`**。
所以想把「天天(UnRealSKY)」在畫面上簡化成「天天」，就在 `alias` 填「天天」，
之後不管重跑幾次同步都不會被改掉。

綁著紀錄的伺服器或頻道不能刪除——那些紀錄的名冊與 Webhook 都靠它。要刪之前先把紀錄改到別的頻道。

> 給管理員：預設來源的兩份檔案在 GitHub 網頁上直接編輯提交即可，不需要重新發版。
> 舊格式（`handle` / `alias` / `id`）仍讀得進來，會自動轉成上面的結構——
> 舊的 `alias` 視為當時的顯示名，歸入 `discordNickName`。

### 用 Bot 自動同步名冊（給管理員）

不想一個個手動複製使用者 ID 的話，設定一次 Discord Bot 之後，在專案目錄跑：

```bash
pnpm members
```

就能一次抓回整個伺服器的成員，自動填好 `discordHandle` / `discordNickName` / `discordId`
（你自己取的 `alias` 不會被動到）。Bot **不需要公開 IP，也不需要常駐服務**，
腳本只呼叫一次 REST API 就結束，網站仍是純靜態站。

> 這件事沒辦法做成網頁上的按鈕：Discord 會擋掉帶瀏覽器 User-Agent 的 API 請求
> （有效 token 也一樣），而 User-Agent 是 fetch 改不了的 header。實測記錄在下面那份文件裡。

Discord 端的設定步驟見 **[discord-bot-setup.md](discord-bot-setup.md)**。
